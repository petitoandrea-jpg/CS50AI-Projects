# CS50 AI — Introduction to Artificial Intelligence with Python

Percorso completato nel 2026: **CS50's Introduction to Artificial Intelligence with Python** (Harvard University), con 12 progetti.

Certificato con verifica pubblica:
https://cs50.harvard.edu/certificates/bf92d2f2-77b6-4bc7-8402-2c77e72848ba

## Progetti

| Progetto | Argomento | Tecnica |
|---|---|---|
| Degrees | Ricerca | Ricerca su grafo (BFS) per trovare il percorso più breve tra attori |
| Tic-Tac-Toe | Ricerca | Algoritmo minimax per un giocatore artificiale |
| Knights | Conoscenza | Logica proposizionale per risolvere enigmi logici |
| Minesweeper | Conoscenza | Inferenza su una base di conoscenza per giocare a Campo minato |
| PageRank | Incertezza | Catene di Markov e calcolo iterativo del PageRank |
| Heredity | Incertezza | Rete bayesiana per inferire la probabilità di un tratto genetico |
| Crossword | Ottimizzazione | Problema di soddisfacimento di vincoli, con coerenza degli archi e backtracking |
| Shopping | Apprendimento | Classificatore k-nearest neighbors per prevedere gli acquisti online |
| Nim | Apprendimento | Apprendimento per rinforzo con Q-learning |
| Traffic | Reti neurali | Rete neurale convoluzionale per il riconoscimento dei segnali stradali |
| Attention | Linguaggio | Modello di linguaggio mascherato e visualizzazione dell'attention |
| Parser | Linguaggio | Grammatica context-free per l'analisi sintattica di frasi |

## Strumenti

Python, TensorFlow, scikit-learn, NLTK, Hugging Face Transformers.
